BeeIRCd, from install to chat

What running your own server would look like: one install on Linux, one command to start, and every service answering in BChat. All names, nicks and addresses below are examples.

The names

My recommendation: drop BeeHive. One name for the thing you download, install and run is calmer than a package name plus a server name. The two web parts keep their own names because people open them separately.

1Install

Unpack, run ./install, answer a few questions. Enter keeps the value in brackets. Nothing is written until you confirm the summary.

root@irc: ~/beeircd-0.1.0
root@irc:~# tar xf beeircd-0.1.0-linux-amd64.tar.gz && cd beeircd-0.1.0
root@irc:~/beeircd-0.1.0# ./install

2Start and check

After that, one command for everything. status is the quick look, check tests the config before a restart so a typo never takes the server down.

root@irc: ~
root@irc:~# beeircd status

  BeeIRCd 0.1.0   ● running  for 3 days 4 h   pid 4121
  Server     irc.beenet.org  · hub of BeeNet
  Ports      6667 plain · 6697 TLS · 7000 links

root@irc:~# beeircd check

  ✓ safe to restart

root@irc:~# beeircd

3In BChat

Services answer as notices, the way IRC always did, with a ConferenceRoom feel: short sentences, tidy lists, a hint for the next step. Pick a service to see it.

Bee connects, identifies, and is opered by services. No /oper line needed.
